# Center for Integrated Systems (CIS) Website

This is the website of our academic research group at [University of Kragujevac](https://en.kg.ac.rs/), Serbia.

This website is powered by Jekyll and some Bootstrap, Bootwatch. The original website comes from the [Allan Lab](http://www.allanlab.org/). The authors have made it simple yet adaptable, so that it is easy for us to use it as a template. We felt free to fork it from [https://github.com/mpa139/allanlab](https://github.com/mpa139/allanlab) and modify for our own purposes.

Go to *aboutwebsite.md* to learn how to copy and modidy this page for your purpose.
